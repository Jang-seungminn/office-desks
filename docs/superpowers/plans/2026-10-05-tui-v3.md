# TUI v3 (split presets, mouse, drag-to-copy) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show 1, 2 (left|right or top/bottom) or 4 agents at once next to the list. Click to select and focus, scroll with the wheel, and drag inside a pane to copy its text to the system clipboard.

**Architecture:**
- **Pure modules.** New pure modules handle SGR mouse parsing (`mouse.ts`), pane layouts (`layout.ts` with presets), the selection model and text extraction (`selection.ts`), clipboard dispatch (`clipboard.ts`) and pane assignment state (`panes.ts`).
- **Compose.** `compose.ts` draws N panes with dividers, a focused pane and a selection overlay.
- **App.** `App` drives the new state. Each shown agent is sized to its own pane and has its own output subscription.

**Tech Stack:** TypeScript ESM (Node 22+), vitest, `@xterm/headless@^6` with `@xterm/addon-unicode11`, and `node-pty@1.1.0`.

**Spec:** `docs/superpowers/specs/2026-10-05-tui-v3-design.md`. Also see the v2 spec and plan in `docs/superpowers/{specs,plans}/2026-10-04-tui-v2*`.

## Global Constraints

- **Platforms.** It must run on macOS and Windows, using npm scripts only and never shell-joined arguments. CI runs typecheck, test and build on `macos-latest` and `windows-latest`. Tests must not depend on real-time windows shorter than about 1 s; inject delays or use `flush()`.
- **Server-only modes.** `npm start`, `npm run dev`, `npm run demo`, `--backend orca`, `--no-tui` and non-TTY runs stay exactly as before. The web keeps working while the TUI runs.
- **Frame width.** Every frame row is exactly `cols` wide. Korean is 2 columns, wide chars are never split, and data text goes through `clean()`.
- **Mouse.** Mouse reporting (`ESC[?1000h ESC[?1002h ESC[?1006h`) is on only while the TUI runs. `RESET_MODES` turns it off, and it already does. Mouse sequences never reach an agent.
- **Copy.** Copying never uses a shell, and arguments go in an argv array. The user's clipboard is touched only by an explicit drag-copy. The `OFFICE_DESKS_COPY_FILE` env var redirects copies to a file. It is a test-only hook and must be documented as such.
- **Agent sizes.** An agent is shown in at most one pane. Selecting an agent that is shown elsewhere swaps the two panes. Every shown agent is resized to its pane's body. Agents not shown keep their size.
- **Style.** Use the `.js` import suffix, 2-space indent, single quotes and short "why" comments. Korean UI text matches the existing voice.
- **Commit messages.** Write a subject, a blank line, then exactly these two lines. Use `git commit -F <file>`.

  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_013wdfUqZP1py6R116oZnY8V
  ```

- **Process discipline.** Anything that starts servers or agents records its PIDs and stops only those. No pkill, killall or pattern kills. Never use port 4317, never touch the user's agents, and use scratch repos and `OFFICE_DESKS_HOME` only.

## Review Focus

1. **Typing into one pane while others stream.** Keys go only to the focused pane's agent. Every shown agent's output re-renders its own pane, and only shown agents trigger renders. Pinned in Task 7.
2. **Mouse sequences in panel focus.** A click or wheel must never type `ESC[<…` garbage into an agent. Sequences split across chunks must also be recognized. Pinned in Tasks 1 and 7.
3. **Copied text equals what is on screen.** This covers Korean text, wrapped lines, a reversed drag and a drag across scrollback. Pinned in Task 3.
4. **Narrow terminals.** A 4-pane preset that doesn't fit falls back cleanly, and the frame stays exact. Pinned in Tasks 2 and 5.
5. **Swapping agents between panes.** No agent appears twice, and sizes follow the pane. Pinned in Tasks 6 and 7.

```ts
// SGR (1006) mouse reports: ESC [ < b ; x ; y M (press/drag/wheel) or m (release), 1-based cells.

export type MouseKind = 'press' | 'release' | 'drag' | 'move' | 'wheelUp' | 'wheelDown';

export interface MouseEvent {
  kind: MouseKind;
  x: number;
  y: number;
  button: number;
  shift: boolean;
  alt: boolean;
  ctrl: boolean;
}

export const MOUSE_SGR = /^\x1b\[<(\d+);(\d+);(\d+)([Mm])/;

export function parseMouse(seq: string): MouseEvent | null {
  const m = MOUSE_SGR.exec(seq);
  if (!m) return null;
  const b = Number(m[1]);
  const base = b & 3;
  const mods = { shift: !!(b & 4), alt: !!(b & 8), ctrl: !!(b & 16) };
  const at = { x: Number(m[2]) - 1, y: Number(m[3]) - 1 };
  let kind: MouseKind;
  if (b & 64) {
    if (base > 1) return null; // horizontal wheel
    kind = base === 0 ? 'wheelUp' : 'wheelDown';
  } else if (m[4] === 'm') kind = 'release';
  else if (b & 32) kind = base === 3 ? 'move' : 'drag';
  else kind = 'press';
  return { kind, ...at, button: base, ...mods };
}
```

### Task 2: Pane layout presets

**Files:**
- Modify: `bridge/src/tui/layout.ts`
- Test: `bridge/test/layout.test.ts`

**Interfaces:**

```ts
export type Preset = 1 | 2 | 3 | 4; // 1 pane, left|right, top/bottom, 2×2
export interface Pane { head: Rect; body: Rect }
export interface Layout {
  title: Rect; listHead: Rect; list: Rect; sep: Rect;
  panes: Pane[];          // 1, 2 or 4 panes, reading order (left→right, top→bottom)
  dividers: Rect[];       // 1-column or 1-row gaps between panes
  preset: Preset;         // the preset actually used (after fallback)
  help: Rect;
}
export function layout(cols: number, rows: number, preset?: Preset): Layout | null; // preset defaults to 1
export const MIN_PANE_COLS = 40;
export const MIN_PANE_ROWS = 6; // body rows
```

Behavior:
- **Pane area.** The area is `{ row: 1, col: sbw + 1, rows: rows - 2, cols: cols - sbw - 1 }`.
- **Preset 1.** One pane covers the area: the head is the area's first row and the body is the rest. With preset 1, `panes[0].head` and `panes[0].body` must equal v2's `panelHead` and `panel`.
- **Preset 2.**
  - The left pane is `lw = floor((area.cols - 1) / 2)` columns wide.
  - A divider column sits at `area.col + lw`.
  - The right pane takes the rest.
- **Preset 3.**
  - The top pane is `th = floor((area.rows - 1) / 2)` rows tall, including its head.
  - A divider row sits at `area.row + th`.
  - The bottom pane takes the rest.
- **Preset 4.** Both splits apply, giving 4 panes in reading order. There are 2 dividers: the full-height vertical one and the full-width horizontal one.
- **Fallback.** If any pane body would be narrower than `MIN_PANE_COLS` or shorter than `MIN_PANE_ROWS`:
  - 4 falls back to 2 (or to 3 if 2 doesn't fit but 3 does), and otherwise to 1;
  - 2 falls back to 1;
  - 3 falls back to 1.

  The returned `preset` reflects the fallback.
- **Too small.** Return `null` below 60×10, as before.

- [ ] **Step 2: Implement `selection.ts`.**

```ts
// A stream selection inside one pane, in the agent's buffer coordinates (so scrolling doesn't
// move it), and the text it covers: wrapped lines rejoined, line ends trimmed.

export interface Point {
  line: number;
  col: number;
}

export interface Selection {
  pane: number;
  anchor: Point;
  head: Point;
}

const before = (a: Point, b: Point) => a.line < b.line || (a.line === b.line && a.col <= b.col);

export function ordered(s: Selection): [Point, Point] {
  return before(s.anchor, s.head) ? [s.anchor, s.head] : [s.head, s.anchor];
}

export function isSelected(s: Selection, line: number, col: number): boolean {
  const [a, b] = ordered(s);
  if (line < a.line || line > b.line) return false;
  if (line === a.line && col < a.col) return false;
  if (line === b.line && col > b.col) return false;
  return true;
}

export function topLine(t: { buffer: { active: { baseY: number } } }, scroll: number): number {
  const base = t.buffer.active.baseY;
  return Math.max(0, base - Math.min(scroll, base));
}

export interface TextBufferLike {
  cols: number;
  buffer: {
    active: {
      getLine(y: number): { isWrapped: boolean; translateToString(trim?: boolean, start?: number, end?: number): string } | undefined;
    };
  };
}

export function selectionText(t: TextBufferLike, s: Selection): string {
  const [a, b] = ordered(s);
  const out: string[] = [];
  for (let y = a.line; y <= b.line; y++) {
    const line = t.buffer.active.getLine(y);
    if (!line) continue;
    const start = y === a.line ? a.col : 0;
    const end = y === b.line ? b.col + 1 : t.cols;
    const piece = line.translateToString(y !== b.line ? false : true, start, end);
    if (y > a.line && line.isWrapped && out.length) out[out.length - 1] += piece;
    else out.push(piece);
  }
  return out.map((l) => l.replace(/\s+$/, '')).join('\n');
}
```

Wrapped lines must be joined *untrimmed*, so a wrapped line's trailing cells are not lost. That is why non-last lines are taken untrimmed and every assembled line is trimmed at the end. If the wrapped-line test fails because of trailing spaces inside a joined line, keep this approach and adjust only the trimming. The joined text must equal what the user sees.

**Files:**

**Interfaces:**

```ts
export type Runner = (file: string, args: string[], input: Buffer) => Promise<void>;
export interface CopyOptions {
  platform?: NodeJS.Platform;
  env?: NodeJS.ProcessEnv;
  run?: Runner;                         // default spawns without a shell, writes input, resolves on exit 0
  has?: (cmd: string) => boolean;       // default: findCommand(cmd, env) from native/env.ts
  writeOsc?: (seq: string) => void;     // OSC 52 fallback (the TUI passes stdout.write)
  writeFile?: (path: string, text: string) => Promise<void>;
}
export function clipboardCommand(platform: NodeJS.Platform, has: (cmd: string) => boolean): { file: string; args: string[]; utf16: boolean } | null;
export function encodeForClipboard(text: string, utf16: boolean): Buffer; // utf16 → UTF-16LE with BOM
export async function copyText(text: string, opts?: CopyOptions): Promise<'file' | 'command' | 'osc52'>;
```

Order of attempts:
1. If `env.OFFICE_DESKS_COPY_FILE` is set, write the text to that file and return `'file'`. This is the test-only hook. Document it in a comment.
2. Otherwise, if a platform command exists, run it and return `'command'`. The commands are:
   - darwin: `pbcopy`;
   - win32: `clip.exe` with UTF-16LE plus BOM;
   - linux: `wl-copy` if present, else `xclip -selection clipboard`.
3. If the command fails or doesn't exist and `writeOsc` is provided, write `ESC]52;c;<base64(utf8)>BEL` and return `'osc52'`.
4. Otherwise throw `new Error('복사하지 못했어요')`.

- **Each pane.**

- **Selection overlay.** For the pane that owns `selection`, set `inverse` on every body cell `(y, x)` where `isSelected(sel, topLine(agent, scroll) + y, x)`. Toggle the cell's existing style rather than replacing it.
- **Cursor.** Only when `focus === 'panel'` and the focused pane has `scroll === 0`, use that pane's agent cursor (carrying `hidden` as in v2). Otherwise fall back to `helpCursor`.
- **Title, list and help.** Unchanged.

export class PaneSet {
  preset: Preset;                 // requested preset (the layout may fall back)
  focused: number;                // index into visible panes

  readonly scroll: number[];      // length 4

  focusNext(dir: 1 | -1, visible: number): void;
  /** Agent ids in visible panes, in pane order, without nulls. */
  shown(visible: number): string[];

  /** Forget agents that no longer exist (pane becomes empty). */

}

- An agent may appear in a hidden slot and in a visible one only after `show()` moved it. `show()` searches **all** slots and swaps with whichever slot holds the agent, so no agent is ever in two slots.
