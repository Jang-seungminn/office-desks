# TUI v2 (sidebar + live panel) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the M3 lobby-or-attach screens with one screen. A sidebar lists projects, worktrees and agents. A live panel draws the selected agent's terminal cell by cell. Ctrl+] moves focus between the two.

The plan also adds:
- `z` to zoom (full passthrough);
- PgUp/PgDn to scroll back;
- `x` to stop an agent;
- `d` to remove a worktree.

**Architecture:** New pure modules sit under `bridge/src/tui/`:
- `cells` holds the style model and SGR.
- `frame` holds the cell grid, width-aware `putText` and the diff painter.
- `layout` holds the pane rectangles.
- `sidebar` renders the list.
- `panel` copies a headless xterm buffer into a rect.
- `input` encodes keys for the agent's terminal modes.

`App` is reworked into a focus/mode state machine. It builds a `Frame` per render and writes only the diff. `PtyHost` exposes each agent's headless terminal. `NativeBackend` gains `stopAgent` and `removeWorktree`.

**Tech Stack:** TypeScript ESM (Node 22+), vitest, `node-pty@1.1.0`, `@xterm/headless@^6`, and `@xterm/addon-serialize@0.14.0` (zoom only).

**Spec:** `docs/superpowers/specs/2026-10-04-tui-v2-design.md`. M3 spec and plan: `docs/superpowers/specs/2026-10-04-m3-tui-design.md` and `docs/superpowers/plans/2026-10-04-m3-tui.md`.

## Global Constraints

- **Platforms.** It must run on macOS and Windows. Use npm scripts only and never shell-joined arguments. CI runs typecheck, test and build on `macos-latest` and `windows-latest`.
- **Server-only modes.** `npm start`, `npm run dev`, `npm run demo`, `--backend orca`, `--no-tui`, non-TTY runs and env-only selections stay server-only. They must behave exactly as in M3. The web keeps working while the TUI runs.
- **Exact width.** Every frame row is exactly `cols` columns wide. Korean and CJK are 2 columns and are never split. Text drawn from agent, desk or repo data goes through `clean()`.
- **Panel focus.** Every key goes to the agent except Ctrl+], in any of its three encodings (`0x1d`, `ESC[93;5u`, `ESC[27;5;93~`). The real terminal always has bracketed paste on while the TUI runs, and `restoreSequence()` turns it off. Paste markers reach the agent only when the agent has bracketed-paste mode on. Arrows follow the agent's DECCKM mode.
- **Zoom** reuses `AttachSession` from M3 unchanged. Leaving it forces a full repaint.
- **Terminal restore.** Every exit path still restores the terminal (M3 `createExit`).
- **Destructive actions** (`x` and `d`) always ask first with `(y/N)`. `d` is refused for the main checkout, for a worktree with running agents, and for a dirty worktree (no `--force`). Branches are never deleted.
- **Style.** Use the `.js` import suffix, 2-space indent and single quotes, with short "why" comments. Korean UI text should match the existing voice.
- **Process discipline.** Anything that starts servers or agents records its PIDs and stops only those. No `pkill`, `killall` or pattern kills. Never use 4317, and never touch the user's running Orca agents or servers. Use scratch repos and `OFFICE_DESKS_HOME` only.

## Review Focus

1. **Panel fidelity.** The panel must show what the agent's terminal shows: characters, Korean width, colors, cursor. This holds after scrollback and after resizes. Pinned in Task 4 (cell-for-cell comparison through a second headless terminal) and Task 2 (diff round trip).
2. **Typing into Claude through the panel.** Plain keys, arrows (DECCKM), paste (bracketed or not) and Ctrl+C reach the agent correctly. Ctrl+] never does. Pinned in Task 6 and Task 8.
3. **Switching the selection while an agent streams output.** Only the shown agent's output triggers renders. Old subscriptions are released. The frame diff stays correct. Pinned in Task 8.
4. **Destructive actions.** `x` and `d` confirm first and refuse unsafe targets with readable messages. A refused `d` changes nothing on disk. Pinned in Task 5 (real scratch git repo) and Task 8.
5. **Resize.** All agents are resized to the new panel size and the screen is fully repainted, with no stale cells. Pinned in Task 7 and Task 8.

```ts
// One terminal cell and its look, as the TUI compositor needs it: read from a headless xterm,
// compared between frames, and written back as SGR.

export type Color = { mode: 'default' } | { mode: 'palette'; index: number } | { mode: 'rgb'; rgb: number };

export interface Style {
  fg: Color;
  bg: Color;
  bold: boolean;
  dim: boolean;
  italic: boolean;
  underline: boolean;
  inverse: boolean;
}

export interface Cell {
  ch: string;
  /** 2 for a wide char, 0 for the column a wide char covers. */
  width: 0 | 1 | 2;
  style: Style;
}

const DEFAULT_COLOR: Color = { mode: 'default' };
export const DEFAULT_STYLE: Style = { fg: DEFAULT_COLOR, bg: DEFAULT_COLOR, bold: false, dim: false, italic: false, underline: false, inverse: false };
export const BLANK: Cell = { ch: ' ', width: 1, style: DEFAULT_STYLE };

export function style(patch: Partial<Style>): Style {
  return { ...DEFAULT_STYLE, ...patch };
}

const sameColor = (a: Color, b: Color) =>
  a.mode === b.mode && (a.mode === 'default' || (a.mode === 'palette' ? a.index === (b as typeof a).index : a.rgb === (b as typeof a).rgb));

export function sameStyle(a: Style, b: Style): boolean {
  return (
    sameColor(a.fg, b.fg) && sameColor(a.bg, b.bg) && a.bold === b.bold && a.dim === b.dim && a.italic === b.italic && a.underline === b.underline && a.inverse === b.inverse
  );
}

function colorCodes(c: Color, bg: boolean): number[] {
  if (c.mode === 'default') return [];
  if (c.mode === 'rgb') return [bg ? 48 : 38, 2, (c.rgb >> 16) & 255, (c.rgb >> 8) & 255, c.rgb & 255];
  if (c.index < 8) return [(bg ? 40 : 30) + c.index];
  if (c.index < 16) return [(bg ? 100 : 90) + c.index - 8];
  return [bg ? 48 : 38, 5, c.index];
}

/** The whole style from a reset; simple and always correct (frames change few runs). */
export function sgr(s: Style): string {
  const codes = [0];
  if (s.bold) codes.push(1);
  if (s.dim) codes.push(2);
  if (s.italic) codes.push(3);
  if (s.underline) codes.push(4);
  if (s.inverse) codes.push(7);
  codes.push(...colorCodes(s.fg, false), ...colorCodes(s.bg, true));
  return `\x1b[${codes.join(';')}m`;
}

export interface XtermCellLike {
  getChars(): string;
  getWidth(): number;
  getFgColorMode(): number;
  getFgColor(): number;
  getBgColorMode(): number;
  getBgColor(): number;
  isBold(): number;
  isDim(): number;
  isItalic(): number;
  isUnderline(): number;
  isInverse(): number;
}

// xterm's color modes: 0 default, 1<<24 16-color, 2<<24 256-color, 3<<24 RGB.
function xtermColor(mode: number, value: number): Color {
  const m = mode >>> 24;
  if (m === 1 || m === 2) return { mode: 'palette', index: value };
  if (m === 3) return { mode: 'rgb', rgb: value };
  return DEFAULT_COLOR;
}

export function cellFromXterm(c: XtermCellLike): Cell {
  const width = c.getWidth() as 0 | 1 | 2;
  const s: Style = {
    fg: xtermColor(c.getFgColorMode(), c.getFgColor()),
    bg: xtermColor(c.getBgColorMode(), c.getBgColor()),
    bold: !!c.isBold(),
    dim: !!c.isDim(),
    italic: !!c.isItalic(),
    underline: !!c.isUnderline(),
    inverse: !!c.isInverse(),
  };
  const ch = c.getChars();
  return { ch: width === 0 ? '' : ch || ' ', width, style: sameStyle(s, DEFAULT_STYLE) ? DEFAULT_STYLE : s };
}
```

```ts
import { BLANK, sameStyle, sgr, type Cell, type Style } from './cells.js';
import { charWidth, clean } from './text.js';

// The TUI screen as a grid of cells. Each render builds a new Frame; diff() writes only the
// cells that changed since the last one (a full paint after a resize or on the first frame).

export interface Rect {
  row: number;
  col: number;
  rows: number;
  cols: number;
}

export class Frame {
  private readonly cells: Cell[];

  constructor(
    readonly cols: number,
    readonly rows: number,
  ) {
    this.cells = Array.from({ length: cols * rows }, () => BLANK);
  }

  get(row: number, col: number): Cell {
    return this.cells[row * this.cols + col] ?? BLANK;
  }

  set(row: number, col: number, cell: Cell): void {
    if (row < 0 || col < 0 || row >= this.rows || col >= this.cols) return;
    this.cells[row * this.cols + col] = cell;
  }
}

export function fillRect(f: Frame, r: Rect, cell: Cell = BLANK): void {
  for (let y = r.row; y < r.row + r.rows; y++) for (let x = r.col; x < r.col + r.cols; x++) f.set(y, x, cell);
}

/** `text` in exactly `width` columns from (row, col): padded, or cut with '…'; never half a wide char. */
export function putText(f: Frame, row: number, col: number, text: string, st: Style, width: number): void {
  const chars: [string, number][] = [];
  for (const ch of clean(text)) {
    const cp = ch.codePointAt(0)!;
    if (cp === 0xfe0f && chars.length) {
      chars[chars.length - 1] = [chars[chars.length - 1][0] + ch, 2];
      continue;
    }
    const w = charWidth(cp);
    if (w > 0) chars.push([ch, w]);
  }
  const total = chars.reduce((s, [, w]) => s + w, 0);
  const limit = total <= width ? width : width - 1;
  let x = 0;
  for (const [ch, w] of chars) {
    if (x + w > limit) break;
    f.set(row, col + x, { ch, width: w as 1 | 2, style: st });
    if (w === 2) f.set(row, col + x + 1, { ch: '', width: 0, style: st });
    x += w;
  }
  if (total > width && x < width) f.set(row, col + x++, { ch: '…', width: 1, style: st });
  while (x < width) f.set(row, col + x++, { ch: ' ', width: 1, style: st });
}

const same = (a: Cell, b: Cell) => a.ch === b.ch && a.width === b.width && sameStyle(a.style, b.style);

export function diff(prev: Frame | null, next: Frame): string {
  const full = !prev || prev.cols !== next.cols || prev.rows !== next.rows;
  let out = full ? '\x1b[0m\x1b[2J' : '';
  let current: Style | null = null;
  for (let y = 0; y < next.rows; y++) {
    let x = 0;
    while (x < next.cols) {
      if (!full && same(prev!.get(y, x), next.get(y, x))) {
        x++;
        continue;
      }
      // Start a run at the head of a wide char whose trailing half changed.
      let start = x;
      if (next.get(y, start).width === 0 && start > 0) start--;
      out += `\x1b[${y + 1};${start + 1}H`;
      let c = start;
      while (c < next.cols && (full || !same(prev!.get(y, c), next.get(y, c)) || next.get(y, c).width === 0)) {
        const cell = next.get(y, c);
        if (cell.width !== 0) {
          if (!current || !sameStyle(current, cell.style)) {
            out += sgr(cell.style);
            current = cell.style;
          }
          out += cell.ch;
        }
        c++;
      }
      x = Math.max(c, x + 1);
    }
  }
  return out ? out + '\x1b[0m' : '';
}
```

The layout uses 0-based rows.
- Row 0 is `title`, full width.
- Row 1 holds `listHead` (cols 0..sbw−1), `sep` (col `sbw`, rows 1..rows−2) and `panelHead` (cols sbw+1..end).
- Rows 2..rows−2 hold `list` and `panel`.
- Row rows−1 is `help`.
- `sbw = clamp(28, 20, floor(cols / 3))`.

```ts
    lines.push({ row: i });
```

```ts
import { BLANK, cellFromXterm, type XtermCellLike } from './cells.js';
import type { Frame, Rect } from './frame.js';

// The selected agent's screen, copied cell by cell from its headless xterm into the panel.

export interface HeadlessLike {
  cols: number;
  rows: number;
  buffer: {
    active: {
      viewportY: number;
      baseY: number;
      cursorX: number;
      cursorY: number;
      getLine(y: number): { getCell(x: number, cell?: never): XtermCellLike | undefined } | undefined;
      getNullCell(): unknown;
    };
  };
}

export function maxScroll(t: HeadlessLike): number {
  return t.buffer.active.baseY;
}

export function drawPanel(f: Frame, r: Rect, t: HeadlessLike, scroll: number): { row: number; col: number } | null {
  const buf = t.buffer.active;
  const top = Math.max(0, buf.baseY - Math.min(scroll, buf.baseY));
  const reuse = buf.getNullCell() as never;
  for (let y = 0; y < r.rows; y++) {
    const line = y < t.rows ? buf.getLine(top + y) : undefined;
    for (let x = 0; x < r.cols; x++) {
      const c = line && x < t.cols ? line.getCell(x, reuse) : undefined;
      f.set(r.row + y, r.col + x, c ? cellFromXterm(c) : BLANK);
    }
    // A wide char cut by the right edge would leave half a glyph: blank it.
    const lastCol = r.col + r.cols - 1;
    if (f.get(r.row + y, lastCol).width === 2) f.set(r.row + y, lastCol, BLANK);
  }
  if (scroll > 0) return null;
  const { cursorX, cursorY } = buf;
  return cursorY < r.rows && cursorX < r.cols ? { row: r.row + cursorY, col: r.col + cursorX } : null;
}
```

`buffer.active.getLine(y)` takes absolute line numbers, and the live screen starts at `baseY`. That is why the code computes `top` from `baseY`, not from `viewportY`. A test in Step 1 already exercises this: it checks scroll position 2 of 5. Keep that test as written.

```ts
// Keys typed into the panel, encoded for the agent's terminal modes. We draw the agent's screen
// ourselves, so modes it switched on (bracketed paste, application cursor keys) exist only in its
// headless terminal; the real terminal always sends normal arrows and wrapped pastes.

const PASTE_START = '\x1b[200~';
const PASTE_END = '\x1b[201~';

function arrows(s: string, app: boolean): string {
  return app ? s.replace(/\x1b\[([ABCD])/g, '\x1bO$1') : s.replace(/\x1bO([ABCD])/g, '\x1b[$1');
}

export function encodePanelInput(chunk: string, modes: { bracketedPasteMode: boolean; applicationCursorKeysMode: boolean }): string {
  let out = '';
  let rest = chunk;
  while (rest) {
    const start = rest.indexOf(PASTE_START);
    if (start < 0) {
      out += arrows(rest, modes.applicationCursorKeysMode);
      break;
    }
    out += arrows(rest.slice(0, start), modes.applicationCursorKeysMode);
    const end = rest.indexOf(PASTE_END, start + PASTE_START.length);
    const body = rest.slice(start + PASTE_START.length, end < 0 ? undefined : end);
    out += modes.bracketedPasteMode ? PASTE_START + body + PASTE_END : body;
    rest = end < 0 ? '' : rest.slice(end + PASTE_END.length);
  }
  return out;
}
```

A paste can arrive split across chunks, with its start marker in one chunk and its end marker in a later one. This function treats a missing end as "the paste continues". The App buffers until it sees `PASTE_END` (Task 8), so `encodePanelInput` only ever sees whole pastes.

- Produces:

```ts
export type Focus = 'list' | 'panel';
export interface View {
  rows: LobbyRow[]; selected: number; focus: Focus; url: string;
  agent: HeadlessLike | null;   // the selected agent's terminal, if alive
  scroll: number;               // panel scroll-back (0 = live)
  help: string;                 // help/notice/form line for the bottom row
  helpCursor: number | null;    // column for the real cursor in the help row (forms), else null
}
export function compose(v: View, cols: number, rows: number): { frame: Frame; cursor: { row: number; col: number } | null };
```

What `compose` draws:
- **Title row:** reversed, showing ` Office Desks · native · 웹 <url>` on the left and the counts `✎ N  ! M ` on the right.
- **List head:** ` 목록`, bold and bright when the list has focus, dim otherwise.
- **Panel head:** `<repo>/<desk> · <agentType>` plus ` · ↑ 기록 보는 중` while scrolled back. It is bold and bright when the panel has focus, dim otherwise. With no agent it shows `(에이전트 없음)`.
- **Separator column:** `│`, bright when the panel has focus, dim otherwise.
- **Sidebar:** drawn with `drawSidebar`.
- **Panel:**
  - With an agent, it is drawn with `drawPanel`.
  - With no agent, it is blank, with a centered dim hint `에이전트가 없어요 — a로 띄우기`.
  - When the selected row's agent has exited, the hint reads `종료됨` instead. Row data without a terminal means exited.
- **Help row:** `help`, fitted to the width.
- **Real cursor:**
  - With panel focus and `scroll === 0`, it is the agent's cursor.
  - Otherwise, when `helpCursor` is set, it is `{ row: rows - 1, col: helpCursor }`.
  - Otherwise there is none.
- **Too small:** when the terminal is under 60×10, the whole frame is blank with ` 창을 키워 주세요` centered.

```ts

  terminal(ptyId: string): (HeadlessLike & { modes: { bracketedPasteMode: boolean; applicationCursorKeysMode: boolean } }) | null;

  host: AttachHost;
  url: string;

```

- `App` keeps its constructor signature `(deps, input, out, escWaitMs = 50)` and its members `start()`, `done`, `handle(chunk)` and `close()`.

**Behavior** (keep the M3 robustness: the serialized input queue, the `closed` flag, escape buffering, id-based selection, `createExit` compatibility):

- **Modes.** The modes are `list`, `panel`, `form`, `confirm` (kind `quit`, `stop` or `remove`) and `zoom`.
- **Start.**
  - Write `ALT_ON + PASTE_ON + HIDE_CURSOR + CLEAR`.
  - Call `resizeAgents(panel.cols, panel.rows)` from `layout(cols, rows)`.
  - Subscribe to `onData` of the shown agent.
  - Render.
- **Shown agent.** The shown agent is the selected row's agent: `terminalOf(row.agentId)`.
  - When the selection changes, unsubscribe from the old agent's `onData` and subscribe to the new one's.
  - Each output chunk from the shown agent schedules a render: coalesce renders in a `setTimeout` of about 16 ms, and run immediately in tests via `escWaitMs` or a `flush()` hook.
- **Render.**
  - Build the `View`, then call `compose`.
  - Write `diff(lastFrame, frame)`, then position the cursor (`moveTo(r + 1, c + 1) + SHOW_CURSOR`, or `HIDE_CURSOR`).
  - Keep `lastFrame`.
  - A resize or a return from zoom sets `lastFrame = null`, which forces a full paint.
- **List keys:**
  - **Movement.** `↑`, `↓`, `k` and `j` move the selection. `PgUp` and `PgDn` scroll the shown agent's history by `panel.rows − 1`, clamped to `[0, maxScroll]`. Decode `ESC[5~` as PgUp and `ESC[6~` as PgDn: add both to `keys.ts` (`{ name: 'pgup' | 'pgdn' }`) with a test. Any other key resets the scroll to 0.
  - **Focus the panel.** `Enter`, `→` or `Ctrl+]` focuses the panel when the row has a live agent.
  - **Zoom.** `z` zooms with `AttachSession` (M3), when the row has a live agent.
  - **Forms.** `a`, `n` and `p` open the M3 forms.
  - **`x` (stop).** It confirms with `에이전트를 종료할까요? <repo>/<desk> · <type> (y/N)`, then calls `stopAgent`. A row without an agent gets the notice `종료할 에이전트가 없어요`.
  - **`d` (remove).** It confirms with `워크트리를 지울까요? <desk> (브랜치는 남아요) (y/N)`, then calls `removeWorktree`. Errors become `⚠️` notices.
  - **Quit.** `q` and `Ctrl+C` quit, with confirmation when agents are running.
- **Panel keys.** Per chunk:
  - If it contains Ctrl+] in any encoding, send the part before it through `encodePanelInput`, then go to list focus.
  - Otherwise, buffer an unfinished paste (`PASTE_START` without `PASTE_END`, so it continues in the next chunk).
  - Write `encodePanelInput(chunk, terminal.modes)` to the agent through `host.write`, guarded with try/catch.
  - If the shown agent has exited, go to list focus with the notice `에이전트가 종료됐어요`.
- **Help line by mode:**
  - **List:** `q 나가기 · Enter 입력 · ↑↓ 이동 · z 크게 · a 추가 · n 새 작업 · p 프로젝트 · x 종료 · d 삭제 · PgUp 기록`.
  - **Panel:** `패널 입력 중 · Ctrl+] 목록으로`.
  - **Form:** the form line plus `  (Enter 다음 · Esc 취소)`, with `helpCursor` set after the typed text.
  - **Confirm:** the question.
  - **Notices** replace the help until the next key.
- **Snapshot change.** Reload the rows (keeping the selection), call `resizeAgents` again so new agents fit the panel (`PtyHost.resize` is a no-op when the size is unchanged), re-subscribe when the shown agent changed, and render. In `zoom` mode, do nothing.
- **Resize.**
  - In `zoom` mode, call `session.resized()`.
  - Otherwise call `resizeAgents`, force a full paint, and render.
- **Zoom.** Reuse the M3 attach code: the mode is set before `start()`, and `onLeave` may fire synchronously. On leave:
  - write `ALT_ON + PASTE_ON + HIDE_CURSOR + CLEAR`;
  - set `lastFrame = null`;
  - resize the agents to the panel again (zoom resized one agent to the full screen);
  - render.

**`main.ts`.** Wire the new deps:
- `stopAgent: (id) => backend.stopAgent(id)`
- `removeWorktree: (id) => backend.removeWorktree(id)`
- `terminal: (pty) => backend.pty.terminal(pty) as …`. The headless xterm `Terminal` has `modes`, so widen the `HeadlessLike` cast.
- `resizeAgents: (c, r) => { for (const id of backend.pty.ids()) backend.pty.resize(id, c, r); }`

**Tests** (rewrite `app.test.ts`). Use real `@xterm/headless` terminals as the agents' screens, and a fake host that writes to them (`host.write` records input; a test helper `emit(id, text)` writes into that agent's headless terminal and calls its `onData` listeners). Cover at least:
